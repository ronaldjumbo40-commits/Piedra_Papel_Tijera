Piedra, Papel o Tijera

Integrante: Ronald Oswaldo Jumbo Amanta

Objetivo

Crear un juego en Python donde una persona pueda jugar Piedra, Papel o Tijera contra la computadora, aplicando los conocimientos aprendidos en Lógica de Programación.

Funcionalidades
Permite al jugador elegir piedra, papel o tijera.
La computadora selecciona una opción al azar.
Compara las opciones y muestra quién gana o si hay un empate.
Herramientas utilizadas
Python
Visual Studio Code
Git y GitHub
Draw.io para los diagramas
