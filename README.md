Piedra, Papel o Tijera

Integrante: Ronald Oswaldo Jumbo Amanta

Objetivo: Crear un juego en Python donde una persona pueda jugar Piedra, Papel o Tijera contra la computadora, aplicando los conocimientos aprendidos en Lógica de Programación.

Funcionalidades:
a. Permite al jugador elegir piedra, papel o tijera.

b. La computadora selecciona una opción al azar.

c. Compara las opciones y muestra quién gana o si hay un empate.

Herramientas utilizadas:

a.Python

b.Visual Studio Code

c.Git y GitHub

d.Draw.io para los diagramas
